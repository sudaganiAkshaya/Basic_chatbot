⭐ TASK 4: BASIC CHATBOT ⭐

🤖 Building a Simple Rule-Based Chatbot Using Python

🚀 Turning Python basics into an interactive chatbot!

This project demonstrates how to build a simple rule-based chatbot using Python.

The chatbot accepts user input and provides predefined responses based on the given rules.

🎯 PROJECT GOAL

The main goal of this task is to create a basic chatbot that can:

💬 Accept input from the user

🤖 Provide predefined responses

🔄 Continue the conversation using loops

🧠 Make decisions using if-elif-else

🚪 Exit the conversation when the user types bye

🛠️ TECHNOLOGIES USED

🐍 Python

💻 VS Code

⭐ KEY CONCEPTS USED

🔹 1. If-Elif-Else

Used to check the user's input and select the appropriate response.

🔹 2. Functions

A function is used to organize the chatbot program.

🔹 3. Loops

A while loop keeps the chatbot running until the user chooses to exit.

🔹 4. Input and Output

input() is used to receive messages from the user, while print() displays chatbot responses.

💬 SAMPLE CONVERSATION

🤖 Chatbot: Hello! I am a simple chatbot.

Type 'bye' to exit.

You: hello

Bot: Hi!

You: how are you

Bot: I'm fine, thanks!

You: bye

Bot: Goodbye!
